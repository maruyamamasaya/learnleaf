# ADR-019: iOSの記事探索を独立した検索タブへまとめる

status: accepted
updated: 2026-10-17

ユーザーが記事を探す操作の使いづらさを挙げ、操作可能な「検索中心」の画面案を選択して実装を依頼した。検索結果より条件UIが大きく表示されること、探索入口が記事ホームのsheetとフォルダタブに分かれていることを改善する。

下部タブをホーム・探す・保存・聴く・設定とする。フォルダと図解/資料は「探す」から開き、資料管理は設定にも残す。検索対象の初期値は記事とし、横断検索の対象選択や既存の詳細条件は別sheetへ移す。上部検索欄と有効条件だけを常時表示し、結果行の読む操作と保存操作を分ける。

検索前は既存catalogのタグ・件数と端末の検索/閲覧履歴を使う。画面案の架空のカテゴリ・説明文を製品へ入れず、本文の自動取得は追加しない。明示的な本文検索と取消・進捗・失敗表示、従来の保存済み検索条件の復元を維持する。

外部のタグ/フォルダ/保存一覧から検索を開く際は条件を設定し、検索タブの遷移を先頭へ戻す。通常のタブ切替では入力と遷移を保持する。保存形式・記事ID・学習記録・音声ファイルは変更しない。ADR-014の個人整理とADR-016のテーマ方針は継続する。
